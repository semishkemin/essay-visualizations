# Grief and Diagnosis

Python visualizations created for an essay on grief, prolonged grief disorder, and the medicalization of bereavement.

## Figures

- `02_diagnostic_timeline.py` — compares the minimum time thresholds used in ICD-11 and DSM-5-TR for prolonged grief disorder.
- `03_prevalence.py` — visualizes the pooled prevalence estimate and 95% confidence interval reported by Lundorff et al. (2017).

Generated figures are available in the `figures/` directory in both PNG and SVG formats.
