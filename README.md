# Essay Visualizations

Visuals, charts, and Python code created for essays by Semish Kemin.

I’m a PhD candidate in healthcare management and a research assistant in the same department. My work is about how health systems are built: how appointments get scheduled, how decisions get made, and how money moves through a room where somebody is sick.

But the questions rarely stay there.

They drift into sociology and philosophy, into what trust actually is, how medical categories are created, what numbers hide, and what we give up in order to receive care.

This repository is the visual companion to that work. It contains the code behind charts, timelines, illustrations, and other figures published alongside my essays.

## What I write about

A note on scope
This is not medical advice. I’m not a physician, and nothing here is intended to tell anyone what to do about their health.
It is not a blame project either. Most people working in healthcare are trying hard inside systems they did not design. What interests me is the design—and the questions it makes difficult to ask.
