# Welcome to the Real World, You're HIV Positive

Python-generated illustrations created for the Semish Kemin essay:

**“Welcome to the real world, you're HIV positive”**

The essay explores the HIV needle urban legend, its spread in the late 1990s, and the fear and stigma surrounding it.

## Illustrations

### Cinema Ticket

`output/cinema_ticket_vintage.png`

A vintage cinema ticket inspired by the late-1990s setting and visual language of the urban legend.

The illustration is generated entirely in Python using Pillow.

### Message Hoax

`output/message_hoax.png`

A recreation of the visual language of a late-1990s forwarded message associated with the HIV needle urban legend.

The message text is adapted from a version of the legend published in _The Austin Chronicle_ in 1999.

## Source

Bartlett S. “About AIDS: An Urban Legend Re-Appears.” _The Austin Chronicle_. Published March 11, 1999. Accessed September 7, 2026.
